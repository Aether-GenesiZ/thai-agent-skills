# Security policy

Security fixes are maintained on the current `main` branch. Older snapshots are
not separately maintained.

Report vulnerabilities privately using GitHub's **Report a vulnerability** button
on this repository's Security page. Do not place credentials, personal data or
exploit details in a public issue. Maintainers will assess reports; no fixed
response deadline is promised.

Skill instructions and bundled examples are reviewed content, but do not form a
security boundary. Agents must retain their own permission and tool policies.
Optional utilities process supplied inputs locally. Model smoke tests use the
user's configured harness and provider; they are never part of default CI.

## Legal and tax content

Domain skills are drafting aids. Check current official sources before relying
on legal, tax, payment or identity guidance. Checksum validation does not prove
identity or authorization. Test data must not contain real personal information.
