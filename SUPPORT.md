# Support

For installation problems or Thai-language errors, open a GitHub issue after
checking the README and existing issues. Include the version, harness and OS,
steps to reproduce, expected behavior, and sanitized error output. Use a short
constructed Thai example and explain its intended meaning or register.

Never post API keys, private company documents, real identity numbers or private
addresses. Report vulnerabilities using the private process in SECURITY.md.
See docs/VERIFICATION.md for tested scope and runtime limitations. Quality depends
on the model; passing a smoke test is not a general Thai-language benchmark.
